## Projenin Amacı

Express.js gibi harici çatı/framework'ler kullanmaksızın yalnızca Node.js'in yerel `http` modülü ve `dayjs` paketi aracılığıyla HTTP yönlendirmelerini, durum kodlarını (200, 404, 405) ve başlıkları (Content-Type, Allow) yöneten bir web sunucusu oluşturmaktır.
